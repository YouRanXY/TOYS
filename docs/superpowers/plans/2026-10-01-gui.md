# Windows GUI Implementation Plan

**Goal:** Provide a double-clickable Chinese desktop file organizer.
**Spec:** ../specs/2026-10-01-gui-design.md
**Architecture:** A FileWorkflow facade coordinates existing core modules.
FileManagerGui presents native controls and delegates operations to a worker.
**Constraints:** C++17, existing src/inclu layout, no overwrites, no global installs.

1. [x] Write failing FileWorkflow tests for side-effect-free previews, apply,
   stale previews, new unpreviewed files, database failures and Unicode queries.
   Implement OrganizationPlan, OrganizationResult and static FileWorkflow APIs.
2. [x] Add native GUI, resource manifest and Windows CMake target. Organize/query/help
   pages share path selectors and table; actions and navigation reflect job state.
3. [x] Add hidden-window GUI integration test, create disposable fixtures, verify
   actual button commands, capture a screenshot, and fix observable defects.
4. [x] Independently review changes; build Debug/Release; run all CTest tests;
   inspect image and diff; update README with double-click instructions.

Ruling: The user's direct request and earlier authorization to continue autonomously
permit routine design decisions and implementation without extra approval stages.
Work stays in the current checkout; no automatic commits or external publication.

Verification: both Debug and Release builds succeeded, and each full CTest suite
passed 7/7 after the final review fixes. Inspected the generated Release preview.
Fixed test synchronization by waiting for the GUI completion handler to return;
the Release GUI flow passed ten consecutive runs before later review additions.
Independent review identified and then confirmed fixes for previewed skips,
link replacements, and high-DPI layout. Added regression tests for disappearing
conflicts and simulated 200% DPI with work-area and list bounds assertions.
Ordinary symlink creation is unavailable on this host, so the link replacement
test reports a permission skip; actual cross-monitor DPI changes were not tested.
